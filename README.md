# Tech Akhil SEO Audit Tool

WordPress plugin for bounded on-page and selected technical SEO auditing, optional focus-keyword analysis, prioritized recommendations, reports, and CSV export.

- **Version:** 1.9.8
- **Author:** Akhilesh Kumar Meena / Tech Akhil
- **Plugin page:** https://techakhil.com/free-seo-audit-tool/
- **Developer profile:** https://techakhil.com/akhilesh-kumar-meena/
- **License:** GPL-2.0-or-later (see plugin header and https://www.gnu.org/licenses/gpl-2.0.html)

## Repository contents

The repository root contains the plugin's installable source files, `readme.txt`, setup guide, and bundled PDF documentation. The WordPress.org directory icon, banners, and screenshots are uploaded separately to the WordPress.org SVN repository's root `assets/` directory after plugin approval; they are not required inside the installable plugin package.

## Install

For WordPress installation, use the separately prepared installable plugin ZIP. Do not upload this GitHub source archive directly through WordPress's plugin uploader.

## Limitations

The crawler does not execute JavaScript and cannot guarantee full-site coverage. Some technical signals are lightweight heuristics and are not a replacement for a full accessibility, security, or ranking audit.
